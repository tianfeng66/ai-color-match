使用说明

所有计算都在你自己的电脑上完成，图片不会上传。建议用新版 Chrome / Edge（Windows、Mac 都可以），Safari 也能用。

单张调色

  1. 「① 原图」放入要调色的照片。
  2. 「② 参考图」放入想要的色调样图（可以多张），点选一张；也可以导入现成的 .cube LUT。
  3. 拖动「强度」「亮度跟随」。大图中线可左右拖，左边原图、右边效果；按住空格看原图。
  4. 导出原分辨率图片、.cube（PS / PR / 达芬奇 / FCPX）或 .xmp（Lightroom / ACR 预设）。

批量调色

  1. 切到「批量调色」，把一批照片或整个文件夹拖进来。
  2. 选参考图或 LUT，选「统一效果」（整批同一个 LUT，风格统一）或「逐张匹配」（每张各算一次）。
  3. 网格里实时显示每张效果，点一张可放大对比；不要的照片点右上角 ✕ 移出。
  4. 点「导出全部」→ 选一个保存位置，会新建「调色输出_日期时间」文件夹，子文件夹结构保持不变。Safari / Firefox 会打包成 zip 下载。

小贴士

  • 亮度跟随 0% = 只换色调、保留原图明暗；100% = 明暗也跟参考图。
  • 内容差别很大的两张图，用「线性匹配」最稳，不会出怪色。
  • HEIC / TIFF 只有 Safari 能打开，Chrome 里请先转成 JPG。
  • 批量导出时可以切到别的窗口，但不要关掉这个网页。
